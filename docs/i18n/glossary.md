# Глосарій перекладу Steel Plast

Єдина термінологія для всіх мов сайту. Ланцюжок перекладу: **українська** (еталон, її
погоджує замовник) → **англійська** (база для інших мов) → **німецька, польська**. При
перекладі з англійської перекладач тримає перед очима й український оригінал, щоб помилка
англійської не розмножилась.

Якщо термін тут є — він вживається саме так, на всіх сторінках. Новий термін спершу
додається сюди, потім у переклад.

## Рішення, які можуть здатися дивними

- **«космічна галузь» → aerospace**: так цю галузь називають покупці в B2B-англійській;
  буквальне «space» звучить як про ракети, а не про постачальників компонентів.
- **«гранули» → pellets**: стандартний англійський термін для сировини термопластавтоматів.
- **«паспорти якості» → quality certificates**: «quality passport» — калька, носій не зрозуміє.
- **«%d хвилин» → «%d min»**: скорочення знімає проблему множини (у польській три форми).
- **Значення «від 1» + підпис «Термін виготовлення від»**: в українському «від» повторюється
  двічі; в інших мовах лишається тільки у значенні, підпис без нього.
- **Підпис «Виготовлення від» під голим числом** (оснащення, штампування): «Lead time from»
  під числом читається погано, тому «Minimum lead time» / «Mindestlieferzeit» /
  «Minimalny czas realizacji».
- **«тонн» → «t»**: англійське «tons» читається як американські короткі тонни (907 кг), і
  цифри здавались би на 10% меншими. Скорочення «t» однозначно означає метричну тонну.
- **«Контакти» → Contact / Kontakt / Kontakt**: в англійській назва розділу в однині;
  «Contacts» — калька.
- **Кальки, яких уникати** (знайшов рецензент англійської): «individual approach» →
  tailored approach, «human factor» → human error, «design bureaus» → engineering design
  firms, «machine-building» → machinery, «technical regulations» про ISO → standards (у ЄС
  «technical regulations» означає обовʼязкові закони).
